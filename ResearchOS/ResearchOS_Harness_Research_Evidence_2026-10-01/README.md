# ResearchOS Harness 调研证据

调研截止2026年10月1日。此包证明调研引擎已实际执行及源码核查的版本，不证明候选产品通过验收。

receipt.json 与 engine.stderr 是原始运行记录。source_status.json 来自实际结果；Reddit虽标ok，同时含timeout，按部分覆盖解释。result.metadata.json是结果元数据提取，保留来源URL和日期，不含完整帖子正文。github-item-verification.json来自官方REST，区分open、closed与merged。source-checkpoints.json记录实读源码版本和文件hash。

X未被技能引擎搜索，报告中的X部分来自补充网页索引和官方项目核查。
