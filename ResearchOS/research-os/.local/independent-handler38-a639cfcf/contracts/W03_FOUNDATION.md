# W03 foundation boundary

This is the implemented construction boundary, not a revision of the frozen v2.0 contract. All 42 formal product cases remain NOT_RUN; W03 has no owned formal cases. `operation_coverage.json` enumerates every OpenAPI operation and its implementation/deferred owner. The executable test compares it with the actual registered HTTP routes.

## Storage and admission

Migration `0002_domain.sql` installs one versioned domain registry, immutable history, typed foreign-key reference rows, contract-specific unique indexes, durable outbox, persistent replay records and server-side credentials/grants. All 31 entity schemas compile from the unchanged specification; the registry refuses unknown entities and validates every service write. VersionRef lookup binds project, type, ID, revision and content hash. Global policy parents are the only projectless cross-scope exception; ordinary references remain project-local. State and lifecycle invariants owned by later WBS are not exposed as a generic HTTP write endpoint.

Project creation atomically persists Profile, unique State, actual GLOBAL/PROJECT BudgetPolicy and RunPolicy defaults, configured source cursors and the creator's explicit project grant. Empty source configurations remain empty; no source queries or external authorizations are invented. Supplied imports/snapshots require W04 and return 503 until that workflow exists. Problem/candidate IDs remain opaque project-local identifiers; there is no invented Problem entity.

Requirements start PROPOSED. The W03 ACCEPT path permits user-stated requirements and observed requirements with version-checked validation references. Assumptions, proposals, revocations and replacements await W04 impact handling. Goals and Tasks are real DRAFT records; Task creation creates/reuses NoProgressRecord and updates the parent Goal. Nullable context is preserved until W04. Tasks may CANCEL or PAUSE while DRAFT. SUBMIT returns 503 pending W04/W06 admission; illegal resumptions return 409. No accepting/reporting/claiming shortcut exists.

Default policies explicitly persist unlimited amount with null cap and the specified global/project concurrency, queue, retry and timing values. Policy mutation/accounting/dispatch remain W12. Goal policies inherit the project policy. EXTERNAL amounts remain decimal strings, timestamps UTC, unknown values null.

## HTTP and content

Strict runtime validation uses pinned `github.com/santhosh-tekuri/jsonschema/v6 v6.0.3`, draft 2020-12 with AssertFormat. Only preloaded local documents resolve; other schema loads fail. RFC 8785 canonicalization rejects duplicate keys, malformed Unicode and nonfinite numbers before schema validation. The library's [official documentation](https://github.com/santhosh-tekuri/jsonschema) documents its draft and format support.

Authentication reads current opaque-token hashes, expiry, revocation, roles and grants from SQLite every request and replay. Roles come only from trusted local administration, never request JSON. OWNER does not inherit EXECUTOR/VERIFIER/SCHEDULER operations. The control binary defaults to loopback and refuses non-loopback until W17 supplies qualified remote access. Device pairing and refresh remain W17.

Local bootstrap: `researchos-control -bootstrap-owner -credential-file <private-file>` uses `RESEARCHOS_DATA_DIR`, creates exactly one OWNER, writes a 256-bit token only to a newly created private file (Windows protected DACL / Unix 0600), and never prints token material. Owner role does not implicitly grant sealing. Credentials expire after 15 minutes; trusted local administration can issue a new short-lived credential through `Service.IssueCredential`. Remote credential lifecycle is deferred W17. The bootstrap database transaction is rolled back and its newly created secret file removed if initialization fails.

Every implemented modifying HTTP request has persistent idempotency. Its fingerprint includes operation, target, query, body and If-Match. Replay returns original status/body/headers only after current authentication, role and scope checks; changing precondition or body under the same key gives 409. Strong revision ETags are required on the exact declared parent; missing headers give 428, stale versions 412. Failed writes roll back domain state, references, events and replay record together.

Upload stores controlled temporary bytes with a random key, hash and expiry. Seal recomputes size/hash, verifies producer and provenance, and makes bytes and metadata immutable. PROJECT content download returns original media type, Digest, nosniff and a sandbox/attachment policy. Artifact metadata visibility is shared by details, lists, replay and event references. Restricted-derived PROJECT seal is denied. The binding for a protected content store is UNBOUND: authorized VERIFIER_ONLY seal/download returns 503 until W17. Synthetic restricted metadata fixtures prove positive authorized Owner/Verifier and negative Executor/Planner visibility without storing formal holdout content. Evaluation Report/Summary schemas are available, but sealing semantic evaluation results and publishing independently confirmed summaries require W10/W17; W03 never fabricates complete evaluation results.

Outbox writes and ProjectState watermark updates occur in the same transaction as domain mutations. IDs and per-project sequence are durable; acknowledgement is idempotent and does not delete events. Current HTTP exposes listEvents; delivery/SSE and recovery consumers remain W12/W13. Read pagination stores immutable, principal/grant/query-bound snapshots; changed roles/grants invalidate cursor reuse. Materializing matching rows is deliberately limited to local project scale; replace with indexed version snapshots when measured size requires it.

## Validation and remaining owners

`python ops/ci/domain.py` executes the real Go tests, records exact invocation and JSON test output, rejects unknown selectors and zero tests. Supported selectors: `RESEARCHOS_TASK_ID=W03`, optional `RESEARCHOS_CHECK_ID=W03-G01|W03-G02|W03-G03`; formal case selectors remain unimplemented. Groups cover actual defaults/migrations/schema, bootstrap, operation inventory, concurrent writes, stale preconditions, replay/revocation, rollback/outbox, references/history, DRAFT lifecycle, content/hash/classification, cursor snapshots and discriminating UTF-16 canonicalization.

W04 owns intent compilation/context/change propagation; W05 execution/runtime; W06 admission/claims/independent acceptance; W07 sources/evidence; W08 cycles; W09 retrieval; W10 experiments/evaluation execution; W11 decisions/qualification; W12 policy/accounting/resources/endurance; W13 projections/SSE/releases/notifications; W15 skills; W16 evolution; W17 protected store/device/TLS/security qualification. Every deferred route returns the contract Error with 503 RESOURCE_UNAVAILABLE after authorization, never empty successful data. W18 owns backup and restore qualification; W03 only proves isolated migration reruns and durable transaction storage.
