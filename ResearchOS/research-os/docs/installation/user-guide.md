# ResearchOS 工作台使用指南

本指南按当前实现说明 11 个页面、可用操作和已有截图。当前分发包仍是 Windows x64 开发夹具，安装范围与启动方法见同目录的 [README](README.md)。夹具启动成功不等于已完成生产激活、获得登录凭据、运行器资格或真实手机验收。以下页面操作以已获授权、已能访问对应项目的服务为前提；包内启动脚本不提供凭据签发或解除激活限制的步骤。

页面行为核对基线为源码提交 `a418d503f29646f62010905f9dc9338630aa0108`。截图来自末尾列出的历史冻结回执，演示真实产品页面配合开发数据的状态，并非本指南编写时重新拍摄。

## 进入工作台与权限

在已批准的服务地址打开浏览器。电脑登录页显示“访问令牌”和“打开工作台”；仅填写受保护管理流程已提供的有效令牌。令牌只留在当前页面内存，刷新或关闭页面后需重新认证。若现有分发环境只显示登录页且没有获授权凭据，应停留在该边界，本指南不提供额外激活或凭据生成办法。

所有读取还需要项目授权；页面能显示一个按钮，不代表当前身份可以执行。无权访问、记录不存在、限流、超时和服务能力未提供会显示对应提示及可能的请求编号。不要把读取失败后的空区域理解为“没有数据”。

| 操作 | 当前服务权限前置 |
| --- | --- |
| 查看获授权项目、证据、成果等 | 具备相应读取角色和项目范围；`READER` 可只读监督，受限产物另行检查权限。 |
| 创建项目 | `OWNER`，并额外获准创建项目。 |
| 工作台提交原始想法 | 当前项目 `OWNER`；原话确认须由同一提交者完成。 |
| 任务暂停、恢复 | `OWNER`、`PLANNER` 或 `SCHEDULER`，且任务处于服务允许的状态。 |
| 请求取消运行 | `OWNER` 或 `SCHEDULER`；仍需执行器确认。 |
| 修改项目费用上限、运行策略 | 当前项目 `OWNER`。 |
| 登记资源请求已解决 | `OWNER` 或 `SCHEDULER`，并提供当前可读的依据。 |
| 标记自己的通知已读 | `OWNER` 或 `READER`，且通知属于当前身份。 |
| 提交背景修改候选 | 创建提案需 `OWNER`、`PLANNER` 或 `SCHEDULER`；本页面还会封存产物，身份另需具备 `EXECUTOR`、`VERIFIER`、`SOURCE_ADAPTER` 或 `SCHEDULER` 之一。只有 `OWNER` 角色不保证整条表单成功。 |
| 管理配对和设备 | 本机 `OWNER`；已配对设备不能再管理设备、创建项目或修改全局策略。 |

独立验收还会检查来源、输入版本与验收者独立性。拥有多个角色、执行结束或点击提交都不能替代验收。

## 页面入口速查

地址中的 `{projectId}`、`{id}` 是已有记录的 ID，不是可照抄的字面地址。可从产品链接进入；没有指定详情 ID 时，周期、任务、成果和实验地址会先显示记录选择页。列表展示当前服务返回的记录，当前界面没有遍历全部历史页的通用翻页控件。

| 页面 | 路径 | 通常从哪里进入 |
| --- | --- | --- |
| 1. 项目入口 | `/` | 点击顶部 ResearchOS 标识或左侧“切换项目”。 |
| 2. 研究工作台 | `/p/{projectId}` | 点击已有项目，或导航“工作台”。 |
| 3. 研究周期 | `/p/{projectId}/cycles/{id}` | 导航“研究周期”；有活动周期时直接打开，否则选择已保存记录。 |
| 4. 任务详情 | `/p/{projectId}/tasks/{id}` | 工作台任务、意图规划或周期后续任务链接；也可打开 `/p/{projectId}/tasks` 选择。 |
| 5. 成果审查 | `/p/{projectId}/releases/{id}` | 导航“成果审查”、最近成果、阶段侧栏或通知。 |
| 6. 来源证据 | `/p/{projectId}/evidence` | 导航“来源证据”或周期候选链接。 |
| 7. 实验与评测 | `/p/{projectId}/experiments/{id}` | 导航“实验评测”先选择，或从周期、技能详情进入。 |
| 8. 知识与技能 | `/p/{projectId}/knowledge` | 导航“知识技能”。 |
| 9. 团队与运行器 | `/p/{projectId}/team` | 导航“团队运行器”。 |
| 10. 费用与资源 | `/p/{projectId}/resources` | 导航“费用资源”、工作台下一步或资源通知。 |
| 11. 设置与设备 | `/p/{projectId}/settings` | 导航“设置设备”。 |

## 1. 项目入口

“已有项目”只列当前身份可访问的项目，点击项目名称打开工作台。“建立项目”要求填写项目名称、要解决的问题和首个明确范围，然后点击“创建项目”。服务创建成功后自动进入新项目。

当前表单仅建立这些基本信息，初始事实、约束、来源配置和文档引用为空。它没有同时上传知识库、配置模型或接入来源的步骤。不能创建时先看权限或服务错误；不要把新项目创建成功当成运行器已就绪。

## 2. 研究工作台

先看“持续目标”“业务已验收”“待评审”，再查看意图规划、当前推进、来源覆盖、最近成果和下一步。业务统计排除意图规划及运行器资格任务；规划提案检查通过只说明规划可追溯、可检验，业务成果另行验收。

提出工作时点击“提出新想法”，填写原话，再点击“确认原话并开始规划”。页面先保存原始 Requirement，再由同一用户确认原话，授权生成可审查规划。未完成提交的原话及提交身份保存在当前浏览器的项目草稿中；刷新后“继续提交”延续同一份提交，已开始的原话会锁定。若出现版本变化，核对原话后使用“核对后重试”，不要反复另建相同想法。

提交成功后从“意图规划”打开对应任务，查看规划、资源缺口及独立检查。点击“当前推进”中的任务可查看执行细节。此页面没有一键宣布业务成功或绕过验收的功能。

阶段侧栏显示各阶段“已验收 / 计划”及进行中、待评审、受阻数量，同时显示计划修订与事件水位。新计划增加任务时分母可能变大；这不表示已验收结果被撤回。未取得投影时显示尚不可用，不推算完成百分比。

## 3. 研究周期

打开周期后，先核对研究时间窗口和来源覆盖，再查看候选与核验、必需实验、后续任务和本轮结论。候选链接会定位到具体证据；实验与后续任务分别打开对应详情。

`PARTIAL` 表示本轮仍有缺口。`NOT_CONFIGURED`、`RATE_LIMITED` 等来源状态以及 `gap_reason` 必须保留解释；来源没有配置、受限或抓取失败，不能解释为“已扫描且没有发现”。只有实际完成覆盖且记录数为零，才有对应窗口内的空结果含义，也不能外推成整个网络没有相关来源。

“本轮尚无候选”可以是合法记录，但是否完成还要看必需来源、实验与结论。负向结论、`NO_IMPROVEMENT` 或证据不足不自动产生采纳，也不自动替换稳定版本。当前页面用于查看回执，未提供手工创建、关闭周期或直接改判候选的按钮。

## 4. 任务详情

页面上方显示任务状态、修订、冻结输入数量和当前 Run 状态。通过“摘要 / 过程 / 产物 / 检查”切换：摘要看执行报告和输入；过程看运行器、执行者、时间与最近关联事件；产物查看封存内容；检查查看独立验收结论及实际检查命令。标签支持方向键、Home 和 End。

| 看到的状态 | 含义与下一步 |
| --- | --- |
| 结果提交／`EXECUTION_REPORTED` | 执行者已上报结果。任务显示“结果已提交”，还不计入已验收。若交接记录使用 `RUN_RESULT`，应核对实际 Task 状态；当前页面没有名为 RUN_RESULT 的状态或独立通过标志。 |
| `VERIFYING`／验收中 | 检查正在进行，仍不是已验收。 |
| `ACCEPTED`／已验收 | 任务通过独立验收；可在“检查”核对回执。意图规划任务的 ACCEPTED 仍不等于业务目标完成。 |
| Run `SETTLED`／执行已结束 | 运行收尾状态，与 Task 的业务验收状态分开。 |
| `CANCEL_REQUESTED`／取消请求中 | 请求已送达，执行器尚未确认；不能当成已取消。 |

READY 或 RUNNING 任务显示“暂停”；BLOCKED 或 DEFERRED_NO_PROGRESS 显示“恢复”；尚未结束、尚未确认取消的活动运行显示“请求取消”。点击后等待服务回执，权限、依赖、状态和版本仍可能使操作被拒绝。页面没有人工填写 PASS、提交运行结果或直接创建验收回执的表单。

## 5. 成果审查

从最近成果或通知进入后，核对成果序号、创建时间、实际变化、开放问题、独立验收、采用决定和下一步。顶部“选择成果版本”可切换已有里程碑；成果序号与软件语义版本分别记录，未发布软件版本会明确显示。

“查看实际检查与命令”展开关联验收回执。“封存产物”固定到该成果引用的修订和哈希；点击“受控预览”后先读取并核对内容。支持文本、简单 Markdown、JSON、图片、PDF 和隔离的无脚本 HTML 预览。普通预览成功后可“下载已核对的内容”；超过 5 MiB 的行内上限或预览出错时可尝试“受控下载”，下载仍核对权限与哈希，不会绕过失效状态。其他格式可下载后查看。

原有产物保持只读。页面没有直接编辑封存内容、将未验收任务变成果或点击采用候选的操作。无采用决定就显示没有关联决定；空白成果列表也不表示执行没有发生，可回到任务检查是否仍在待评审。

## 6. 来源证据

使用检索词、来源、有效性、UTC 抓取日期范围及独立来源标识筛选列表。点击一条证据打开右侧详情；选中 ID 写入 `?focus={id}`，复制地址、前进后退或重新认证后可回到该证据。其他筛选条件是当前页面状态，不承诺刷新后保留。

“服务端检索”需要非空检索词及筛选结果中的封存快照。它检索这些快照，最多请求 20 条命中，不是在线全网搜索。结果显示原文定位、摘录和有效性，点击“定位证据”可返回该条证据。出现警告或检索失败时保留其含义，不将失败改称无结果。

详情包含证据种类、核验状态、有效性、原文 URL、上游版本、抓取时间、源头关系及快照哈希。未建立独立来源关系、模拟判断和已过期来源不能仅凭条目数当成独立支持。该页没有重新抓取来源、手工建立独立源关系或更改核验结论的控件；来源受限应回研究周期查看覆盖缺口。

## 7. 实验与评测

选中实验后核对假设、预注册哈希、测量模式、冻结范围和验收回执，再比较逐指标基线、候选与结果。`NO_IMPROVEMENT`、`INCONCLUSIVE` 都是合法结果，不触发稳定版本自动替换。

“评测资格”列出服务返回的资格记录，不能将任意一条列表记录当成当前实验的资格证明；开发夹具也不替代正式资格。费用与完整性以关联报告为准，没有报告时保持未知。对于可访问的聚合评测 JSON，受控预览可展示预期、观测、通过、失败、错误、弃权、缺失、重复计数，以及费用、完整性和固定哈希。正式留出逐题内容不在工作台展示。

当前页面用于核对结果及报告，没有新建、预注册、启动实验或直接授予正式资格的表单。

## 8. 知识与技能

点击技能版本查看状态、作用范围、修订、来源覆盖、失败来源、待处理冲突、独立验收、回滚版本与许可信息。存在关联实验时可跳转，内容产物使用同样的受控预览。

“已处理 / 预期来源”要与失败数、冲突数一起看；候选与稳定版本的状态不能互换解释。当前页面没有技能创建、晋升、撤回或回滚按钮，记录中存在回滚版本 ID 也不表示这里可以执行回滚。缺服务能力时看明确错误，不把空列表当作已完成知识归纳。

## 9. 团队与运行器

“运行器”列出名称、状态和健康检查时间，点击“查看”展开能力与资格原始信息。“当前执行”展示服务返回的最近运行记录及状态，可能包含已经结束的运行；不是只有在线执行者。“Agent 消息”展示最近记录。

登记、健康探针、真实运行与独立资格分别核对。一个角色名称或一条运行器记录不代表有在线员工，也不代表供应商已获正式资格。页面没有安装、登录、登记运行器、启动外部 CLI 或改变执行者权限的操作。无法运行时应查看资源请求与实际阻塞原因。

## 10. 费用与资源

先看当前金额策略和待处理资源，再读逐笔账目。“未知或待结算”对应缺少金额的记录，底层 `money=null` 不是金额 0；`UNKNOWN` 也不应计为已结算。页面按运行与供应商请求的最新记录区分已结算、在途预留和未知，同时保留逐笔金额、币种及费用依据，不提供跨币种合并总额。

获授权 Owner 可在“修改项目上限”选择“不设金额上限”或“设定上限”。设定上限时填写金额、币种，并选择严格上限或按估算执行，点击“保存上限”。严格上限在费用未知时阻止新执行；估算方式允许记录未知费用，不能保证最终账单不超额。不设上限也不代表无限余额、供应商可用或没有并发限制。

每条资源请求列明原因、受阻任务、可继续任务、保留产物、预计费用与恢复检查点。处理完实际缺口后，点击“登记解决”，填写解决依据，选择封存产物或来源证据，输入已有 ID，再点击“提交服务核查”。页面先读取并固定依据的修订，服务检查请求状态与引用有效性后登记解决；这不证明外部资源已恢复可用，也不直接恢复任务。输入错误、权限不足或版本变化时根据提示修正后再试，仍需核对后续执行状态。

## 11. 设置与设备

“研究与运行策略”可修改并发上限、研究周期秒数和时区，再“保存运行策略”；其余策略字段沿用已加载值。界面最小输入为并发 1、周期 60 秒，最终约束仍由服务检查。该操作不能替代来源接入或运行器资格。

“项目背景候选”只编辑项目意图文本。点击“编辑项目背景草稿”冻结当前修订，编辑后选择“封存候选并请求重验”。成功表示已生成封存 JSON 候选和 ChangeProposal，等待独立验收，尚未直接覆盖项目背景。

若外部修订已变化，页面并列保留本地草稿与外部背景，要求填写“人工合并后的背景”，再点“保存双方并提交合并候选”。双方文本与合并候选分别封存，不自动覆盖旧稿。可随时“导出保留的草稿”；与工作台原始想法不同，这里的未提交编辑主要在当前页面状态，离开或刷新前应导出。权限不足时保留当前草稿，并交由有封存权限的执行者处理，不能通过按钮绕过角色检查。

“来源配置”当前只读展示类型、范围、启用与必需标记；凭据不返回前端，没有公开的凭据配置表单。

“设备”仅在已获批准并启用的入口下使用：电脑 Owner 填写设备名称与已审核的入口 origin（不含路径），点击“生成只读配对链接”，再复制给目标设备。外部入口要求 HTTPS；链接五分钟内一次有效。手机打开链接、填写名称并“配对并打开工作台”，默认只读当前项目。电脑可显式“允许项目控制”、恢复只读或撤销设备。配对会话只留在页面内存，刷新或关闭后需重新配对；设备不能据此获得其他项目、受限产物或电脑管理权限。此流程的实现与开发证据不等于真实手机已验收；入口尚未批准启用时保持本机访问。

## 双主题、窄屏、通知与恢复

顶部“深色 / 浅色”切换主题，偏好保存在当前浏览器。桌面显示左侧导航及右侧阶段进度；中等宽度会收起文字与进度栏，可用顶部进度按钮打开。小于 768 CSS 像素时使用左上“打开导航”抽屉、右上“打开阶段进度”抽屉，以及底部工作台、周期、成果、资源四个入口。抽屉可用关闭按钮、遮罩或 Escape 关闭；打开时焦点限制在抽屉内，关闭后返回原按钮。截图中的 390px 是浏览器视口宽度，不是真实手机型号。

顶部通知按钮打开自己的通知，可“标记已读”并跳转到关联成果或资源。已读状态与业务验收分开；重复接收事件不应生成重复业务结果。

连接断开时页面提示“状态可能过期”及最后同步时间；尚未取得数据时显示尚未同步。最后同步表示收到快照或业务事件的时间，空闲心跳不是新的业务进展。普通请求超过约 30 秒会报超时；SSE 长时间静默会中止旧连接并重新核对快照。重新可见、页面恢复或检测到长时间停顿也会触发快照核对。

连接恢复后先确认最新状态，再决定是否重试。使用统一写入入口的任务、策略、通知操作会在已同步后断线时阻止发送；其他表单仍可能尝试请求并显示失败，不能假定所有按钮都被禁用。界面没有统一离线写入队列，也不会在重连后自动重发全部控制操作。原始想法有自己的同一提交重试机制；其他表单应先核对服务记录与当前版本，避免把超时理解成必然未执行。
