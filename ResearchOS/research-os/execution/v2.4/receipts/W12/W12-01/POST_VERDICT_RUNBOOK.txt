落地 attempt-budget 探针前必须满足的三条（04:06Z 逐行核实，别再靠猜）
1. 领取响应形状：orchestration.go:447 返回 {task, run, lease_token}。lease_token 在**顶层**，
   run 是嵌套对象；因此 epoch 只能从 claimOut["run"]["lease_epoch"] 取，不能从顶层 Num 取（我早先的补丁稿写错了）。
2. report 的门禁（runtime.go:144）：要求 p.ID == run.executor_principal_id、epoch == 当前 lease_epoch、
   Digest(lease_token) == run.lease_token_hash、且 now < lease_expires_at。⇒ 探针必须用**执行者凭据**
   （IssueCredential(executorID) 换一张 token 赋给 h.token 再 POST /report），用 owner token 会被拒。
3. 租约 TTL 只有 90 秒（runtime.go:49 lease_expires_at = now+90s）。观测+report+RESUME 的整轮必须在
   领取后 90 秒内完成，或按 fixture 一样先 /heartbeat 续约；否则失败原因会是过期而不是预算耗尽，
   那又是一个"因错误理由变绿/变红"的断言。
