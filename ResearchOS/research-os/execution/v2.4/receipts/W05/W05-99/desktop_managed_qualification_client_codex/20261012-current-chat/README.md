The Desktop main process now owns the private inherited-pipe control child, checks installed control/verifier/Mu assets and Windows process identity, and keeps PREPARE/CONFIRM/STATUS scoped to the trusted native host, selected session, writer and model. The renderer gets only four no-argument qualification actions and a visible one-call, zero-tool, unknown-cost confirmation. CONFIRM is one-use. A missing installed bundle fails closed; a broken management pipe with a child whose exit has not been observed blocks normal window and smoke exit rather than silently abandoning that child. The public client-wire build includes and binds `openapi.json` for the normal Desktop protocol route.
