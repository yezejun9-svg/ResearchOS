# Private Desktop management protocol — candidate, not yet independently accepted

Launch the normal control executable with `--desktop-management-stdio --runtime-verifier-manifest <absolute installed manifest>` and the existing data directory, working directory, discovery arguments, runtime assets and environment. Hold dedicated child stdin/stdout pipes. Do not detach, unref, share these pipes, forward renderer bytes, copy native credentials into them, or attempt management of an already-running external control. stderr remains diagnostics. No second coordinator, manager service or release journal is created. Core captures its actual Windows parent PID / creation time / image digest and same-OS-user identity and rechecks every input frame.

Transport: UTF-8 NDJSON, one JSON object per line, maximum 65,536 bytes excluding newline. Duplicate keys, unknown fields, malformed encoding, trailing JSON and unsupported operation terminate the management link without replay or forced host termination. First output is READY:

    {"protocol":"researchos-desktop-management/1","kind":"READY","host_id":"host-…","control_process":{"PID":123,"CreatedNS":"1791790000000000000","ImageSHA256":"…"},"parent_process":{"PID":456,"CreatedNS":"1791790000000000000","ImageSHA256":"…"},"mode":"IN_PLACE","confirmation_ttl_seconds":60}

CreatedNS is a decimal string; never convert it to a JavaScript Number. PID remains a bounded integer. This corrects the initial pre-test draft that used an unsafe JSON number; the failed first fixture is preserved in attempt04. Main must bind READY to the child it launched and its own process identity and retain the exact logical `host_id`. This private channel is separate from frozen /v2/command and Native3. No renderer gets direct write access to child stdin. Main constructs the frame from trusted current client context and an explicit user action.

Every request has `protocol`, unique transport `message_id` (1..128 characters), `operation`, and exact `host_id`.

- PREPARE adds only `project_id`, `session_id`, `model_config_ref`. It performs offline preparation and records a short-lived immutable confirmation in the existing authority database. It makes zero model calls. RESULT.result has `state: AWAITING_CONFIRMATION`, `request` (full frozen nonsecret request), `request_hash`, `model_calls: 1`, empty `tools`, `purpose: mu_turn`, `purpose_seconds: 600`, `cost_basis: UNKNOWN`, `money: null`. Display this decision and ask for explicit confirmation. Never equate prepare with authorization.
- CONFIRM adds only `project_id`, `request_id`, `request_hash` from that exact preparation. It runs at most one bounded qualification call, independent verifier, existing server acceptance, and exact Owner purpose permission. All normal route dispatch and session execution intake stay fenced until settlement. Begin atomically checks original Host/Owner root, session revision/writer, config hash, plan/profile, issue/expiry (60 seconds maximum), immutable confirmation hash and one-time consumption. Success returns `QUALIFIED_PURPOSE_AUTHORIZED` and original receipt refs. Failure may still have consumed the request: do not retry or automatically generate another confirmation.
- STATUS adds the same `project_id`, `request_id`, `request_hash` and reads original database records, including after expiry or lost CONFIRM response. Returns `AWAITING_CONFIRMATION`, `EXPIRED`, `UNRESOLVED`, `EXECUTION_SETTLED`, or currently revalidated `QUALIFIED_PURPOSE_AUTHORIZED`, with consumed/run/runtime fields when present. It never executes or renews purpose.
- SHUTDOWN has no scope fields. It invokes actual current drain/quiesce and refuses busy/unresolved state; no strong kill. Success replies `SHUTDOWN_ACCEPTED` then the child completes its normal shutdown. Process exit, not response alone, confirms shutdown/lease release. If current drain policy cannot release UNKNOWN cost history, keep that refusal; this branch does not alter accounting.

Replies are `{protocol, message_id, operation, host_id, kind: RESULT, result}` or `{..., kind: ERROR, result, error: {code: MANAGEMENT_REJECTED, message}}`. There is only one operation in flight. Wait for the original response; do not resend CONFIRM on timeout. Once admitted, host settlement uses the host context, not pipe lifetime. Link EOF or write failure leaves host/data/session/diagnostics and consumed records intact; reconnect requires a later managed process lifecycle, not external takeover. Core restores an unresolved managed qualification dispatch fence from original Run/effect/dispatch rows after process restart.

No request file is created by this producer. Existing startup file consumption additionally requires absolute regular nonredirected path, protected exact current-user DACL, strict JSON, and the same pre-existing DB confirmation; its expiry is not extended.

Public Go producer: host.NewDesktopManagement(h, service, coordinator, apiURL, installation, input, output, safeShutdown).Serve(ctx). Internal Host obtains and revokes short Owner/verifier credentials; none enters wire frames or renderer.

Evidence class for this candidate: Source + synthetic fixture only; actual local / paid models and protected holdout are not run.
