## Smallest useful boundary

If a product experiment is later authorized, derive a deterministic model-visible schema projection from frozen `model_config.tools` and check that names, descriptions, parameters, and strictness stay in lockstep with the Go validator at worker initialization. Keep the existing Go authority, effect ledger, and host executor as the only dispatch. This is a local pure transformation/contract check; it should not import the DSH registry or use its terminal or approval lifecycle. DSH's exact implementation has `deferLoading` and a different tool-definition shape, so it is a pattern reference, not drop-in code.
