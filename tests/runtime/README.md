# W05 runtime

`ops/ci/runtime.py --mode fixture|live` runs nonzero W05 assertions and preserves command/environment/version evidence before execution. Set `RESEARCHOS_GO` to the pinned Go 1.27.1 binary. Select `RESEARCHOS_CHECK_ID=W05-G01` for 27 protocol/service/native Windows assertions; `W05-G02`/`A04` requires explicit `RESEARCHOS_RUNTIME_LIVE=1` and `--mode live`. Empty, unknown, mode-mismatched, missing or duplicate assertion selections fail. Optional `--subcase` only reruns the affected live subcase and reports `SUBCASE_ONLY`, never full A04 acceptance.

The Windows adapter owns one admitted Run and its finite command queue. Durable intent precedes an atomic Job Object process assignment; the job disallows breakaway and kills descendants on worker handle loss. A process is suspended at creation and resumed inside the job. PID plus creation time is recorded. A named exclusive journal lock prevents another worker from taking the same run. Unknown outcome after a worker crash is retained as UNKNOWN and never automatically retried. Monotonic lease/time deadlines stop launches and terminate the complete job. Default heartbeat/lease is 15s/90s. Parent exit alone is insufficient while children remain.

This is process lifecycle management, not W17 sandbox/credential isolation. Native session resume is unsupported; recovery uses a new current ContextBundle only after the previous outcome is reconciled. CLI `turn.completed`, tool exit and process exit are separate observations; none accepts a Task. Model revision and cost remain null when the provider does not disclose them.

`go build ./ops/runtime` produces a runnable worker. `runtime.exe -request <private request.json> -journal <new directory>` accepts `spec` (run_id/task_id/epoch/commands/model/expected_outputs), `inputs` (one stdin prompt per command), `codex_home` (explicit authorized runtime auth home), and optional `timeout_seconds`. The coordinator sends `{ "operation": "renew"|"cancel", "epoch": 1, "reason": "..." }` as stdin JSONL. EOF never extends a lease. `-reconcile -journal <existing>` performs no dispatch and returns nonzero for UNKNOWN. Requests must originate at the trusted local coordinator; this CLI does not grant admission or upload/accept results.

The service's `BeginRuntimeQualification` local entry admits only owner-authorized, dependency-free DRAFT tasks with exact `task_type=runtime_qualification`. It validates a persisted current bundle, creates a real Run with monotonic epoch, and grants the executor only that Run. `ObserveRuntime` is a trusted local bridge with no HTTP endpoint; report/cancel ACK cannot manufacture its observations. A success additionally requires sealed bytes matching every adapter output manifest entry; a log alone is insufficient. `UNKNOWN` maps to `RECONCILING`, and both it and LOST retain the active-run database fence. Normal READY admission and final Task acceptance remain W06.
