## A2 与维护边界

实际完成入口包含 issues 路由的 3 个 transition 调用、execution-workspaces 调用，以及 plugin-host-services 直接 issues.update。reviewPolicy 的部分敏感更改有事务内复核，不能忽略这些保护；executionPolicy 清空、其他写入口与冻结输入、产物 hash、run/epoch、验收回执的不可跳过约束仍未证明。SDK PluginDatabaseClient 暴露 query/execute，事件由 notifyWorker 通知，没有本轮已证明的跨 core/域同步 veto 合同。

## 后续唯一架构

W02 只建立一个 Go 控制服务、React 工作台、SQLite 权威库。Go 统一拥有身份、Goal/Task/Run、调度、租约、预算、事务、事件与 /v1；Windows Worker 只执行委派并保存恢复日志。单实例、本机 SQLite WAL、外键、可靠同步、忙等待和短写事务。独立 verifier 验证后，服务器原子核验当前版本、身份、hash、回执并释放后继。薄核心尚未实现，全部相同不变量须在后续重新证明。
