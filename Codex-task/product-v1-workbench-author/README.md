# Product V1 default workbench source handoff

The existing Desktop React workbench now defaults to Codex readonly ephemeral Tasks and offers the original Mu workflow in the same layout. Codex does not require a provider ModelConfig and does not invent a V2 Session. Its input, history, status, whole assistant messages and tool observations use the frozen Harness contract through a narrow Main/preload bridge.

The Go Host remains the Task/Run/event authority. QUEUED acknowledgements have no Run and do not imply completion. Decimal revisions, epochs and cursors remain strings. A cursor reset adopts the authoritative snapshot; a new Run/epoch keeps earlier Task events. Cancellation carries the exact current revision and nullable Run/epoch pair. No stale-CAS retry is automatic.

The Main-owned journal uses the existing protected application userData directory. Prompts are private user data. It atomically retains the original request/body/hash and native Host/dataRoot namespace before dispatch; it stores neither credentials nor authoritative server Task state. An uncertain submission survives Main restart. Corrupt, failed or full journals block dispatch without silently evicting unresolved records. Recovery only reads the original request. NOT_FOUND keeps the uncertainty barrier. There is no manual resubmit button in this first slice.

Revision2 reports PLATFORM_POLICY for hooks/MCP. This describes platform-managed policy, not proof of filesystem enforcement. Execution, read scope and cancellation verification remain independent. Write, execution resume/pause, per-tool approval, token deltas, files/diffs/artifacts and attachments are disabled for Codex V1. The original Mu file/diff and permission paths remain available in its existing branch.
