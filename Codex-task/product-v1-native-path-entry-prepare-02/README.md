Microsoft primary-source boundaries:

- [SendMessageW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendmessagew)
  and [SendMessageTimeoutW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendmessagetimeoutw)
  document system marshalling for messages below WM_USER and timeout failure.
- [WM_SETTEXT](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-settext)
  and [WM_GETTEXT](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-gettext)
  specify Unicode string/read-buffer semantics. The candidate uses only 0xC/0xD
  with bounded 0x23 flags; no custom LPWSTR, remote memory, or global keyboard.
- [GetWindowTextW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindowtextw)
  cannot read another application's Edit; direct WM_GETTEXT is required.
- [PostMessageW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-postmessagew)
  and [BM_CLICK](https://learn.microsoft.com/en-us/windows/win32/controls/bm-click)
  support the inference of a pointer-free queued standard click. Posting proves
  queue acceptance only. The verified dialog must be foreground; actual warning
  or closure is required. No SetActiveWindow or activation fallback is used.
- [GetAncestor](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getancestor)
  supplies the true parent; [GetWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindow)
  supplies GW_OWNER. [IsWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-iswindow)
  warns of handle recycling, so actions require fresh identity checks.
