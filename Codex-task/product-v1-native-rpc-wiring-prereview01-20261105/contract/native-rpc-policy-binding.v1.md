## 4. Same OS pipe and bounds are mandatory

Create one real OS capture pipe and pass its same inheritable write handle as BOTH child stdout and stderr; stdin remains a separate pipe. A single reader preserves actual bytes. Passing stdout/stderr to two pipes and merging Go callbacks does not satisfy this contract. Close parent duplicate child-write handles after launch and maintain existing Job ownership. No f13/Kernel changes.

The Native arg0 helper failure warning is synchronously emitted before app-server initialization. On the one pipe it cannot be hidden behind a response due solely to separate reader scheduling. Scan raw bytes across chunk boundaries for that warning and startup failure diagnostics. Preserve bounded raw capture and reject malformed/interleaved/truncated/undecodable protocol before the turn; never skip corruption until a later valid JSON response. The finite allowlist of benign diagnostics and expected RPC notifications belongs to the pinned protocol parser, not a generic ignore-non-JSON rule. Setup warning text, incomplete trailing bytes at the candidate barrier, duplicate IDs or an unexpected request prevent minting. Post-barrier protocol errors stop the run; this does not retroactively prove zero external activity.

Use the existing per-run timeout/Job limits without increasing them. First implementation adds a preparation deadline <=45 seconds within the existing overall 300-second domain timeout, a capture ingestion ceiling of 8 MiB, per-frame ceiling 1 MiB, existing execution-input ceiling 1 MiB, and bounded event count at or below current driver limits. Limits apply to actual ingestion/processing, not just retained prefixes. On limit/error, persist the bounded available evidence and stop via Job; do not continue unbounded hashing. Raw Native diagnostics are potentially sensitive: retain only in the established restricted Host receipt path and redact public events; never emit config/auth content as new public proof. Exact limits are part of template/implementation identity and must be reflected in tests.

Normal helper inference additionally requires fixed normal home with no PATH separator and no CODEX_HOME injection. Successful setup prepends the new directory and retains its guard. If any of these source preconditions cannot be established, block; do not inspect private helper files or trust a name prefix from inherited PATH.
