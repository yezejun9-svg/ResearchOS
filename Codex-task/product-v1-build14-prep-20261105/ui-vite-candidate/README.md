# UI candidate production Vite stage

Status: candidate, **not registered or executed**. Root must first receive and review the final exact6 freeze manifest (freeze03 if it supersedes freeze02), then pass its absolute `manifest.json` directory and full SHA to `register_ui_vite.py --register --freeze-dir ... --freeze-manifest-sha256 ...`. The registrar writes only C files: `registration.json` here and a new controller `scopes/product-v1-workbench-refinement-vite-01.json`. It does not create the stage or launch Node. Root reviews the emitted scope SHA and then invokes the unchanged, pinned `owned_run.py` once. A consumed scope is never replayed.

The scope uses `purpose=build`, 120 seconds, 24 processes, 3072 MiB, pinned Python and Node, and the original f13 owner. The runner copies the UI lease worktree's actual `apps/web/src`, `index.html`, `package.json`, `package-lock.json`, any `vite.config.*` and `public`, plus the two imported production files `apps/desktop/main/lib/wire-values.mjs` and `spec/v2.0/ui/design-tokens.json`, into a fresh C stage. It creates a junction in that stage's `apps/web/node_modules` to the existing offline web cache and runs the same Node/Vite `build --outDir` form as `apps/desktop/build-validator.py`. There are no changes to UI WT sources, WT dependencies, imports, or configuration, and no installation.

All six freeze paths are verified against the UI WT, including the two test files. The scope pins every staged source file, the UI lease, the entire 365-file offline dependency closure, the frozen manifest, `INPUTS-02.json`, the original `TARGET.readback.json`, Node, Vite, runner, registrar, and controller. `copy_public_web.py`'s original readback algorithm verifies the tree metadata and bytes before and after the build. The C stage retains raw Vite output, asset hashes, and source drift status. This is a candidate build only; no App, Native, CLI, runtime, model, or formal acceptance is claimed.

Final freeze manifest SHA and exact6 digests are intentionally unresolved until the owner delivers the new freeze. `MANIFEST.json` in this folder pins these candidate scripts and fixed references.
